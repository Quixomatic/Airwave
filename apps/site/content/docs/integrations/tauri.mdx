A server-sent events (SSE) stream is on the way for live, always-connected clients like a Tauri desktop app.
This page will cover connecting, the event stream, and reconnection.
</Callout>

Polling is fine for a Tidbyt or a Home Assistant sensor, but a desktop app or a live wall-mounted dashboard
wants updates the moment they happen. An SSE endpoint at `/api/public/v1/events` will let a client hold one
long-lived connection and receive events (now playing, the guide advancing, sessions starting and stopping) as
a stream.

## What to expect

- One authenticated `GET /api/public/v1/events` connection using your API key.
- The same event types as webhooks, delivered as an SSE stream instead of individual HTTP pushes — ideal for a
  [Tauri](https://tauri.app/) client that stays open.
- Automatic reconnection with last-event resumption.

Until then, poll `/guide/now` and `/now-playing` on a short interval — see
[Generic REST](/docs/integrations/rest).
