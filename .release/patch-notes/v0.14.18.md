## Highlights

- **Run the Airwave server however you like:** Docker (`docker compose`), a single `curl` / `irm` command, or a native desktop supervisor app that bundles everything (embedded Postgres included).
- **Every major platform can now run the Airwave client:** Apple TV, Fire TV, Roku, Android TV, LG webOS, Samsung, any browser, and native Windows, macOS, and Linux desktop apps.
- **Three ways to build a channel:** a metadata filter, Plex playlists and collections, or a hand-picked manual list.
- **A major overhaul of the AI lineup builder,** in both how it runs and how you watch it: live observability tracing, a replay scrubber, a Stop that truly cancels, and dry-run previews you can commit without re-running the AI.
- **Big scrubbing and seeking quality-of-life upgrades** on every platform except Roku: a live preview that commits a single seek, press-and-hold on the remote, and mouse click-and-drag on the desktop and in the browser.
- **The browser TV player got a major revamp** to catch up to the polished tv-tauri desktop clients: a full mouse-and-keyboard browser mode.
- **`pnpm dev:setup`** takes a fresh clone to a running dev stack in one command, for contributors.

## New Features

- **Build a channel three ways.** Alongside the metadata **Filter**, two new content modes:
  - **Playlists & collections:** build a channel from one or more Plex playlists or collections, unioned in order, with shows and seasons expanding to their episodes and a live preview before you save.
  - **Manual:** hand-pick individual movies, shows, seasons, and episodes with an instant library search, drilling show to season to episode. A whole show stays live, so new episodes join on the next build.
  - The AI assistant now understands and can build/edit all three modes (approval-gated), with new tools to browse playlists and collections and drill into episodes. Filters stay the default.
- **The AI lineup builder is now observable and controllable.** Live progress tracing across every phase, a replay scrubber that reconstructs the run at any instant, a floating action bar, a Stop button that truly aborts in-flight model calls (not just future steps), a dry-run preview you can commit as a real lineup with no AI, and a "rebuild one channel" that re-runs just that channel in place.
- **Z.ai (GLM) as a first-class cloud AI provider:** a cheap or free planner with a reasoning-effort knob, so you can pair a cloud planner with a local worker for near-free lineups without a GPU.
- **One-line self-host installer** for the Docker stack: `curl -fsSL https://www.getairwave.tv/install.sh | sh` (Linux/macOS/WSL) or `irm https://www.getairwave.tv/install.ps1 | iex` (Windows). Checks Docker, asks a few questions with sensible defaults, generates your secrets, writes the compose file and `.env`, and brings it up. Re-run to update; `--advanced`, `--dry-run`, and `--uninstall` too.
- **A browser mode for the web TV player** (Docker / desktop server): keyboard shortcuts, click-to-play, hover-highlighted controls, hover sidebars, a two-step guide click, and mouse click-and-drag scrubbing. Real TV builds are unaffected.
- **Smoother rewinding and fast-forwarding on every platform except Roku.** The arrows now slide a live preview and commit a single seek when you stop (one reload instead of many), on webOS, the browser player, the desktop app, and the Apple TV / Fire TV / Android TV / iPad apps, including press-and-hold on the remote. Mouse users can click or drag the scrubber on the desktop app and in the browser.
- **The Linux desktop client is fully available** (Windows, macOS, and now Linux): it builds, runs, plays, and self-updates like the others.
- **Roku on-device email/password sign-in** (the fix for the Channel Store rejection), plus a Play/Pause remote binding and a content-sized Info panel.
- **Apple TV Play/Pause remote button** now toggles the playing channel.
- **Admin quality-of-life:** clone a channel, copy and paste filters between channels, preview a channel from your unsaved filter before saving, a proper OTP field on the device-approval page, and a device-code shortcut so viewers (and app reviewers) are never stranded on the admin page.
- **Configurable AI build/import concurrency** and a per-connection "disable thinking" toggle for local models.
- **Desktop app:** run-at-login, silent startup, and LAN/workflow-on defaults for a Plex-like background server.
- **One-command contributor onboarding** (`pnpm dev:setup`): a fresh clone to a running dev stack, with generated + preserved secrets.

## Fixes

- **Android TV HDR overhaul:** the player picks the right video output up front from the program's dynamic range, so HDR plays at the correct aspect ratio (no zoom or stretch), HDR-to-SDR switches cleanly, and rewinding across a program no longer restarts it from the beginning.
- **NVIDIA Shield purple-screen** on SDR video is fixed (falls back to the classic renderer on Shield only).
- **Apple TV / iPad freeze** from a main-thread deadlock is fixed via an async libmpv port, plus a client-side freeze detector so any future freeze is visible.
- **Transcoded streams no longer get killed mid-playback** (a Plex liveness ping keeps the session alive).
- **AI on local models:** filter tool-calls now work, keyless local endpoints work, the ~300-second timeout is gone (it was a Bun fetch watchdog), and the parallel-builds setting is actually applied.
- **The desktop database starts on a clean Windows box** (the MSVC runtime is bundled), an orphaned Postgres is reaped on restart, and the app reclaims its own ports.
- Smaller fixes: the setup checklist stops polling forever once setup is done, Spacebar works in the browser player's full-screen panel, and blog dates no longer show a day early in behind-UTC timezones.

## Improvements

- Audio / subtitle / quality menus are now proper centered dialogs on the webOS/browser player and the desktop client.
- The desktop clients keep the machine and display awake during playback.
- Every destructive action in the admin now uses a real in-app confirm dialog instead of the browser prompt.

## Docs

- Self-hosting docs refresh: numbered steppers, the full `docker-compose.yml` and `.env` shown inline, and a documented stable `PLEX_CLIENT_IDENTIFIER`, with download links pointing at the downloads page.
- A local / self-hosted models guide: the two settings that decide whether a local model works, the planner's step-duration limits, concurrency tuning, and a known-good config.
