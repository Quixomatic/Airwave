## Highlights

This release makes the built-in channel presets genuinely good and overhauls how they are generated, adds an MCP tool server for driving Airwave from an AI client, and makes filtering across the whole app much faster. Auto-generating channels is now a staged, non-destructive flow with live preview and observability, every built-in channel was rebuilt and validated against a real library, channel filters now resolve in a single query per library, and channels and packages show how they were made at a glance.

## New Features

- **Preset generator, rebuilt.** Auto-generating channels is now a staged, human-in-the-loop flow instead of a destructive wipe-and-rebuild. A staging page (Channels, Auto-generate, Preset generator) lets you pick channels across packages, preview the exact matches per channel before committing, and confirm a net create / update / delete plan. Builds reconcile against what you already have (create new, update changed, delete removed, leave the rest untouched), run as a durable workflow or a background job with crash-resume, and have their own observability page (Settings, Workflows, Preset runs) with a replay timeline and a Stop control.
- **Recommended starter lineup.** The staging page defaults to a curated, cross-package recommended set on a first run instead of the whole Basic package, with a Recommended button to reselect it anytime. A previously generated lineup still pre-selects exactly what you built.
- **Show rotation.** Every shuffle channel that carries TV now airs a group-by-show rotation (short blocks of one to three episodes per show, reshuffled each lap), so a long-running series no longer hogs the channel.
- **MCP tool server.** A new `apps/mcp` stdio server exposes all of the assistant's tools to any MCP client (such as Claude Desktop), authenticated by an admin API key you manage from a new API Keys settings page.
- **Provenance badges.** Channels and packages now show a PRESET or AI badge (with an icon), on the channels list, the packages list, and the channel and package edit headers, so you can see at a glance how each one was created.

## Improvements

- **Much faster filtering.** Channel filters now resolve in a single Plex query per library, using Plex's native advanced-filter grouping, instead of fanning OR and nested filters out into many queries and combining them in memory. It is result-identical to before, several times faster across the board, and up to roughly 78x faster on the heaviest OR and nested filters. It is switchable back to the old resolver in one place if ever needed.
- **Faster, lighter channel previews.** The channel builder previews (both the live preview as you edit a filter and the saved-channel preview on page load) now skip the heavy per-file stream details and fetch only what the poster grid needs, the same as the preset preview. Combined with the faster resolver, previews feel dramatically snappier.
- **Filter resolver correctness.** A filter predicate that cannot apply to a given library (a movie-only field like duration on a TV library, or a genre exclusion for a genre the library does not have) now drops out of its group instead of silently emptying the whole channel. Filters that mix movie-only and TV-only conditions now behave the way the Plex web UI does.
- **Every built-in channel reworked.** The whole catalog was rebuilt and validated against a real library: channels pick a lane (movies or TV) where the content clearly leans one way, TV network brands (HBO, FX, AMC, Netflix, Apple, Paramount, Showtime) match on the airing network so they carry their series, grown-up channels drop the anime and kids cartoons that used to flood them, sci-fi is split into films and series, and dozens of empty or mislabeled channels were fixed. Basic is trimmed to a tight set of essentials.
- **Safer, more sensible kids channels.** Kids channels are rating-capped so dark TV-14 anime stays out, and family, comedy, drama, crime, horror, and curated channels no longer fill up with content that does not belong.
- **AI lineup safety.** Selecting the AI-lineup tile now warns and confirms before the destructive build, and the old Auto-Generate Lineup job opens the preset generator instead of wiping your lineup.
- **Preset staging polish.** The per-channel preview hovercard opens to the side and is styled like a framed panel with a single scroll.
- **Preset run observability** moved under Settings, Workflows (alongside the AI-lineup and import run pages).

## Fixes

- Prestige TV, Elevated Horror, and other channels were coming up empty because they filtered on signals that do not exist at the TV-episode level, or on studios most libraries do not tag; they now fill correctly.
- Love Stories is real romance again instead of anything carrying a stray love-subplot tag.
- Admin API keys are no longer rate limited.

## Docs

- Self-hosting docs restructured to lead with Docker (the quick start and the one-line installer), and the desktop docs corrected (builds are signed and notarized for Apple Silicon and Intel).
