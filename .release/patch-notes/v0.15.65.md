## Highlights

This release makes channel lineups portable between Airwave servers. Export your whole lineup, a single package, or a single channel to a JSON file and import it on another server. Hand-picked and collection/playlist channels now travel too, alongside the filter channels that already did.

- Export a whole lineup, one package, or one channel.
- All three channel types import now: filter, hand-picked, and collection/playlist. On the same server they import as-is; on a different server their titles are matched to your library by TMDB / TVDB / IMDb id, with a "matched X of Y titles" report.
- A versioned format keeps older exports importable and rejects a file from a newer Airwave cleanly.

## New Features

- **Share channel lineups between Airwave servers.** Export your whole lineup, a single package, or a single channel to a portable JSON file, then import it on another Airwave server.
- **Hand-picked and collection/playlist channels now import, not only filter channels.** They used to be dropped on import. Now they come through for real:
  - **Same server** (re-importing onto the box the lineup came from): the channel imports exactly as-is. A membership channel stays a live collection/playlist, a manual channel keeps its picks.
  - **Different server**: the channel's titles are matched to your own library by their TMDB / TVDB / IMDb ids (a fast lookup, with a live Plex fallback for anything not yet synced) and rebuilt as a hand-picked snapshot. The import reports "matched X of Y titles", skips the ones it can't place, and imports the rest.
- **Channel settings that used to be lost now travel too.** An exported channel carries its grouping and rotation strategy, its Exclude specials and Keep multi-part together toggles, and its shuffle seed, so an imported channel plays the same way the original did.
- **A versioned exchange format.** Every export carries a schema version with a real compatibility policy: an older export is upgraded on the way in, so every file ever exported still imports, and a file from a newer Airwave is rejected cleanly instead of mis-imported.

## Improvements

- **The import staging screen is clearer about what you're importing:** a manual or collection/playlist channel from another server shows how many of its titles match your library before you import, and channels you already have, now including hand-picked and collection/playlist ones, are flagged as "already imported" and left unchecked so a re-import onto the same server doesn't duplicate them.
- **Exports are complete even without a prior re-sync:** if a referenced title's metadata ids aren't cached yet, the exporter fetches them live from Plex while exporting, so a hand-picked or collection/playlist channel exports complete.

## Fixes

- **Cloning a membership or manual channel now loads its preview automatically.** Cloning already pre-filled the new channel with the source channel's full setup for every mode, but the Preview panel only auto-loaded for filter channels; a playlist/collection or hand-picked clone sat on "Nothing to preview yet" until you nudged it. It now previews on load whatever the channel mode. (The channel edit page is unchanged.)
- **The recently-added scan no longer wipes freshly captured metadata ids.** The quick incremental scan that runs every few minutes was overwriting the TMDB/TVDB/IMDb ids on the newest items in each library; it now keeps them.
