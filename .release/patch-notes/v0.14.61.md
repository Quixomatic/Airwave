## Highlights

A polish and maintenance release: the admin dark theme was retuned to a cooler, more cohesive blue-black, and device capability probing now caches its test media so repeat detection uses far less bandwidth.

## Improvements

- **Dark theme retune.** The admin dark mode moved from a warm, flat near-black to a cooler, more cohesive blue-black. Surfaces are lifted so the page no longer reads as a flat black, text gets a subtle cool tint with stronger muted-text contrast, and the primary accent is re-hued toward the light theme's blue. The onboarding checklist card in the sidebar is now a solid, properly elevated panel, and the dark sidebar grain was re-toned to match.
- **Lighter device capability probing.** The short clips a TV plays to detect what it can natively decode are now cached on the device (immutable), so each clip is fetched at most once instead of being re-downloaded on every probe. Repeat capability checks use far less bandwidth.

## Under the hood

- **Cloud Service groundwork (dormant).** Internal scaffolding for a future optional, opt-in Cloud Service was added behind a feature flag that is off by default. It is inert and does not affect self-hosted operation.
