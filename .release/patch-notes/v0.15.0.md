## Highlights

Airwave gets a public integration API: a documented, key-authenticated way to read your self-hosted server's live data and receive its events, so you can wire it into Home Assistant, Tidbyt, a Tauri app, n8n, or anything that speaks HTTP. Read the guide, channels, packages, and who's watching over REST; pull program artwork as ready-to-use image URLs; receive signed webhooks when someone starts or stops watching; or hold a live SSE stream for an always-connected dashboard. It ships with an interactive API reference and integration guides on getairwave.tv.

## New Features

- **Public integration API (`/api/public/v1`).** A new, separate REST surface for outside integrations (Home Assistant, Tidbyt, Tauri, n8n, generic REST), kept apart from Airwave's internal TV-client and admin APIs so its contract can stay stable. Authenticate with the existing `airwave_` API key (Settings, API Keys), sent as `X-API-Key` or `Authorization: Bearer`. It publishes a first-party OpenAPI 3.1 spec at `/api/public/v1/openapi.json` with an interactive Scalar reference at `/api/public/v1/docs`. Every endpoint is read-only and scoped to what the key's user may access:
  - **Server:** `GET /status` (product, version, install id, display name, uptime, live counts) and `GET /capabilities` (API version, features, and whether webhooks or the SSE stream are available).
  - **Channels:** `GET /channels`, `/channels/{id}`, `/channels/by-number/{number}`, `/channels/{id}/now` (now and next with the live offset), and `/channels/{id}/schedule`. `?include=definition` adds a channel's authoring internals.
  - **Packages:** `GET /packages` and `/packages/{id}` (with its channels).
  - **Guide / EPG:** `GET /guide` (the now/next grid, `?forwardMinutes` / `?backMinutes`) and `/guide/now` (a compact one row per channel, small enough for a Tidbyt).
  - **Now watching:** `GET /sessions`, `/sessions/count` (the cheapest "is anyone watching" sensor), and `/now-playing`.
- **Program artwork.** A tokenless artwork proxy (`GET /api/public/v1/channels/{channelId}/artwork/{ratingKey}`) streams a program's poster (or `?kind=background`) straight from Plex, and every program and session carries a ready-to-use `artworkUrl` you can drop into an `<img>` or a Home Assistant `entity_picture`. No API key or Plex token is needed for the image itself. (Replaces the earlier raw `artworkPath` field; switch any use of it to `artworkUrl`.)
- **Webhooks.** Airwave pushes a signed event to any HTTPS endpoint the moment something happens, so an integration reacts instead of polling.
  - Signed with the [Standard Webhooks](https://www.standardwebhooks.com/) scheme (HMAC-SHA256), verifiable with an off-the-shelf library.
  - Delivered through a durable outbox drained by a dedicated in-process worker: retries with backoff, per-request timeouts, and auto-disable after repeated failures. Fire-and-forget, and free when no webhooks are configured, so it never affects playback.
  - Managed from a new **Settings, Webhooks** tab (add/edit endpoints, event-type checkboxes, secret shown once, enable/rotate/test, per-endpoint delivery log), and over the public API (`/api/public/v1/webhooks/*`) so an integration like n8n can register its own endpoint.
  - Events today: `session.started` and `session.ended` (a channel change surfaces as a stop then start), plus a `ping` test event; `playback.*` are defined and marked "coming soon."
  - A daily Webhook Log Cleanup job trims old deliveries so the log can't grow without bound.
- **Live event stream (SSE).** `GET /api/public/v1/events` streams the same events over one long-lived connection, for always-connected clients like a Tauri app or a dashboard. Authenticate with the `X-API-Key` header or an `?api_key=` query parameter (so a browser `EventSource` works); `?types=` filters.
- **Editable server display name.** Each install gets a display name (for example "Sapphire Vole - Airwave Server"), auto-generated on first run and editable under Settings, General. It appears in `/api/identity` as `name` so a client can label a discovered server.
- **Public `/api/identity` discovery endpoint.** Returns `{ product, version, instanceId, name }` so a client can confirm a server is genuinely Airwave and recognize a specific install. `instanceId` is a stable per-install id, local-only, never phoned home.

## Improvements

- **Refreshed admin login page.** A faded grid pattern plus a subtle cool aurora glow along the bottom edge, over the app's noise texture in light and dark. The logo lockup moved inside the card, sizing was tightened, and the card shadow softened.

## Docs

- **API Reference on getairwave.tv.** A new API Reference section renders the public API's OpenAPI 3.1 spec with an interactive playground, grouped by tag, reachable from the docs sidebar's root switcher. "Try it" targets a spec-driven mock so it returns example data with no real server; a second server entry points at a self-hosted address.
- **Integration guides** under a new "Extend Airwave" group: Generic REST, Home Assistant, Tidbyt, Webhooks, and Live events (SSE), plus an Integrations overview.
