## Highlights

This release is mostly about giving channels more control over what airs, plus some self-healing when a Plex library disappears. You can now keep multi-part episodes together so a split story plays in order, and exclude TV specials from a channel's pool. A deleted Plex library no longer breaks every job: a new Library Health check disables a library that has vanished and turns it back on if it returns, with a status badge on the Sources page. Local and OpenAI-compatible AI connections can send custom request headers, stored encrypted. The channel editor also gets a floating section nav and a redesigned Schedule panel with a now-playing card and a vertical lineup timeline.

## New Features

- **Keep multi-part episodes together** (issue #37) (0.15.43–0.15.45): a per-channel toggle in the channel editor. With it on, consecutive episodes that make up one split story (titles like "… (1) / (2)", "… Part 2", or "… (II)") play back to back and in order wherever they land, whatever the ordering or grouping strategy. Detection is title-based, since that is the only signal the media server exposes: a run has to start at part 1 and tops out at 5 parts. Bumpers still play between the parts. Off by default, and with it off the schedule is unchanged. The AI assistant can see the setting when it describes a channel.
- **Exclude TV specials from a channel** (issue #7) (0.15.46–0.15.47): an "Exclude specials" toggle at the top of the Advanced grouping and rotation section. Turn it on and Season 0 episodes drop out of the channel's pool, so specials never show up in the schedule, in every mode (filter, membership, manual). Movies and regular seasons are left alone. Off by default.
- **Library Health: recover from a deleted Plex library** (issue #36) (0.15.37–0.15.40): a new check runs every 15 minutes and confirms each source's libraries still exist on the server. A library that has gone missing (deleted in Plex, for example) is disabled automatically after three failed checks, so metadata sync, library scans, and schedule builds stop failing on a section that is no longer there. If it comes back, it is re-enabled on its own. The Sources page shows a per-library badge (Healthy, Missing n/3, or Not found), and a library you turn off by hand stays off.
- **Custom request headers for local AI connections** (issue #58) (0.15.41): a compatible AI connection's Advanced settings now have an "Extra request headers" editor with add and remove rows. Those headers go out on every request to that endpoint, including the connection Test, so an endpoint that requires a header can finally be used (OpenCode Go, which rejects anything without `x-opencode-session`, is the case that prompted it; a custom `User-Agent` is another). Headers are stored encrypted, the same as the API key, and reserved transport and auth headers cannot be overridden.

## Improvements

- **A floating section nav in the channel editor** (0.15.49–0.15.50): on wide screens an "On this page" nav lists the channel's sections, plus Preview and Schedule, and highlights whatever is in view as you scroll. It overlays without changing the form's width, and hides when there isn't room or when the AI assistant panel is open.
- **A now-playing card in the Schedule panel** (0.15.50–0.15.51): the now-playing block now matches the active-session card in Settings, showing the show or movie poster, the program details, and a progress bar with elapsed and total time.
- **The upcoming lineup is now a vertical timeline** (0.15.51–0.15.52): a timestamp and a dot on the rail for each program, with the title, its badges (season and episode, resolution, audio, content rating), and length alongside. The program on now is the active step, and breaks appear inline between programs.
- **Clearer scheduling toggles** (0.15.48): the switches in Advanced grouping and rotation put the switch in a left gutter next to its label and a short description, in place of the full-width blurb under each one.

## Fixes

- **The "Keep multi-part episodes together" toggle now saves** (0.15.45): it used to always read as off and lose a change on save, because the edit and clone pages assembled their form values and save payload from a fixed list of fields that left the new toggle out.
- **The now-playing show poster shows without a re-sync** (0.15.53): the channel editor's now-playing card reads the show's poster from the parent show's cached metadata at request time, so it appears right away on existing libraries instead of waiting for a fresh metadata sync.
