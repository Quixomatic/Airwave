## Highlights

Turning on subtitles forces Plex to transcode, and that transcode can take 30 seconds or more to start, longer on low-power hardware like a Raspberry Pi. Both the browser and desktop players used to give up before it was ready. This release makes them wait it out and show that something is happening, so enabling subtitles now buffers and then plays instead of erroring on a black screen.

## Fixes

- The browser player (tv-web) no longer errors with "Stream error (manifestLoadError)" on a slow subtitle transcode. It now retries the stream's manifest with exponential backoff for about 50 seconds before giving up, so a slow start rides through to playback the way buffering already does.
- The desktop player (tv-tauri) no longer gets stuck on a slow subtitle transcode. mpv now reconnects through Plex's "still warming up" 503 responses instead of treating them as a dead stream.

## Improvements

- The desktop player (tv-tauri) shows a buffering spinner while a stream is loading or rebuffering, so a slow transcode start reads as "it's working" rather than a frozen screen. The spinner floats over the current frame and is hidden while paused.
