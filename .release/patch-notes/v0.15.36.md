## Highlights

This release is mostly about building Manual channels faster. The Manual builder gets a real search: type `genre:`, `actor:`, `decade:` and the like to filter your library by its Plex tags, pick values from an autocomplete, and stack several filters at once. And if you already have a Filter channel, one button now turns whatever it currently matches into a hand-picked Manual pool. Channel schedule builds are also serialized per channel now, so two builds running at the same time can no longer append duplicate timeline rows.

## New Features

- **Smart search in the Manual channel builder** (0.15.28–0.15.29): type a prefix to filter by a Plex tag alongside plain title search: `genre:`, `actor:`, `director:`, `studio:`, `rating:` (content rating), `resolution:`, `decade:`, `year:`, `audience:` (minimum rating), plus `hdr:` / `dovi:` flags. Typing a prefix opens a dropdown of matching values from your own library and narrows it as you type; picking one commits a chip. Several chips of the same kind are OR'd, different kinds are AND'd, and bare text filters by title on top, so `decade:2010` plus `actor:Tom Hanks` plus `the` all combine. It all comes from the synced library cache, with no extra calls to Plex. Facets apply to movies and shows; episodes match on their own title.
- **Convert a Filter channel into a Manual pool** (0.15.36): a "Convert to Manual" button in the channel editor's Filter mode, next to Copy and Paste. It resolves whatever the filter matches right now and drops the result into a Manual pool, then switches the editor to Manual mode with those items filled in, the same as if you had picked them by hand. Nothing is saved until you save the channel as usual, and the filter stays put, so you can switch back before saving if you change your mind. It follows how Manual mode treats shows: a show whose every episode matched becomes the live show (so later episodes still follow it), a show that only partly matched keeps just its matched episodes as a snapshot, and movies come across as themselves.

## Improvements

- **Facet palette and chip polish in Manual search** (0.15.30–0.15.35): a facet palette sits under the search bar and lists every filter you can use (Genre, Actor, Director, Studio, Rating, Resolution, Decade, Year, Audience, HDR, Dolby Vision). Click one to start that filter, or type to narrow the list, so "gen" leaves just Genre. The active filter shows as an inline chip with its value typed inside it and a button to cancel it, and Escape or Backspace clears it. The builder's empty states, both the search results and the "In this channel" pool, are more compact and no longer take up a full panel's height.
- **Channel schedule builds run one at a time per channel** (0.15.22–0.15.27): two `generate`, `extend`, or `repair` builds on the same channel used to be able to overlap and write duplicate timeline rows. A per-channel database lock now serializes them. Background jobs skip a channel whose build is already running and stop waiting if they are cancelled, and the admin Generate and Extend buttons say a build is already running rather than hanging. A lock left behind by a crashed or hung build clears itself after five minutes, and any lock still set from a crash or redeploy clears at startup, so a channel is never stuck unable to rebuild. Different channels still build in parallel.

## Fixes

- **The iPad status bar no longer overlaps the app** (0.15.19–0.15.21): on iPad, the tv-native guide and settings pages now sit below the status bar, with a band in the sidebar color behind it so the bar reads as its own strip. The space is reserved from launch, so coming back from full-screen playback no longer snaps it into place. iPad only; Apple TV, Android, and iPhone are unchanged.
