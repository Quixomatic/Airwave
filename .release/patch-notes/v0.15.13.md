## Highlights

This release makes Airwave installable as a non-root container, which opens up the TrueNAS SCALE community catalog (and Podman, rootless Docker, and Kubernetes) with no change for existing root-based setups. It also ships the device enrichment the admin Sessions page and public API were built for, and adds the by-number public API now/schedule endpoints.

## New Features

- Run the container as an arbitrary non-root user. The entrypoint now detects whether it was started as root. As root (the default) it behaves exactly as before: sets the timezone, remaps the `app` user to PUID/PGID, chowns, then drops to that user with gosu. Started as a non-root user, it skips the root-only steps and runs the selected role directly as that user. This is what lets Airwave install from the TrueNAS SCALE community catalog, and it also covers Podman, rootless Docker, and Kubernetes `runAsUser`. Purely additive: existing Dockge / docker compose / installer setups take the unchanged root path.

## Improvements

- The admin Sessions page and the public session endpoints now return each session's full device info (platform, model, OS version, HDR, isTV, and Samsung Tizen recognition). The resolver was built for 0.15.9/0.15.10 but left out of those commits, so until now the deployed server still returned the bare `{ id, model, platform }` shape. The public `/sessions` and `/now-playing` endpoints carry it too.

## Fixes

- `GET /api/public/v1/channels/by-number/{number}/now` and `/schedule` now exist. Only the `/channels/{id}/...` variants were implemented, so the by-number paths (used by the Tidbyt integration example) returned 404 for any channel. Both by-number variants now resolve the number to the channel (honoring enabled + API-key access) and return the same now/next and schedule payloads as the by-id routes. Regenerated the OpenAPI spec so the reference pages and docs mock pick them up.
- The web / tv-web roles build under a non-root uid. Those roles build their SPA at container start, writing across the app tree (a transient vite config bundle, the TanStack Router codegen into `src/`, and the `dist/` output); those dirs are now writable by any uid so the startup build completes when the container runs non-root. Part of the non-root image work above.

## Platforms

- Airwave can run as a non-root user, enabling the TrueNAS SCALE community catalog path plus Podman / rootless Docker / Kubernetes.
